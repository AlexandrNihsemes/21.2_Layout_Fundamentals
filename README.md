# 21.2 Layout Fundamentals

Домашняя работа: вёрстка прототипов на Bootstrap 5 и Flask-приложение, которое отдаёт страницу «Контакты».

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | Прототип «Главная» |
| `catalog.html` | Прототип «Каталог» |
| `category.html` | Прототип «Категория 1» |
| `contacts.html` | Прототип «Контакты» (его же отдаёт сервер) |
| `404.html`, `500.html` | Страницы ошибок (доп. функционал) |
| `app.py` | Flask-приложение |
| `requirements.txt` | Зависимости |
| `.gitignore` | Исключения для git |

## Запуск

Все файлы должны лежать в одной папке — рядом с `app.py`.

```bash
# 1. виртуальное окружение (если ещё не создано)
python -m venv myenv

# 2. активация
myenv\Scripts\activate        # Windows
source myenv/bin/activate     # Linux / macOS

# 3. зависимости
pip install -r requirements.txt

# 4. запуск
python app.py
```

Сервер поднимается на `http://127.0.0.1:5000`. Процесс должен «висеть» — это нормально, остановка через `Ctrl+C`.

## Как проверить

- `http://127.0.0.1:5000/` — открывается страница «Контакты».
- Любой другой адрес, например `http://127.0.0.1:5000/orders`, тоже отдаёт «Контакты» (требование задания: любой GET → «Контакты»).
- `http://127.0.0.1:5000/test-404` и `/test-500` — демонстрация страниц ошибок.

POST-запрос (доп. задание) — через форму на странице «Контакты» или из терминала:

```bash
curl -X POST -d "name=Иван&email=ivan@example.com" http://127.0.0.1:5000/contacts
```

Все принятые данные (метод, заголовки, form, тело) печатаются в консоли.

## Бонус

Прототипы из задания 1 — обычные статические файлы: их можно открыть двойным кликом в браузере, сервер для них не нужен. Навигация между страницами работает через боковое меню.
